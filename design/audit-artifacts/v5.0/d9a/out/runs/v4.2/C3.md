## Three problems found first

1. **The reference in this Skill gets the hook schema wrong.** `cc-skills-and-hooks-composition.md` §4–§5 says "exit code 1 blocks completion" and shows a `matchers`-based config. Per Anthropic's docs, exit 1 is a non-blocking error. A Stop hook blocks by exiting 2, or by exiting 0 and printing `{"decision":"block","reason":...}`. Config entries use `matcher` plus a nested `hooks` array. **[Anthropic docs: code.claude.com/docs/en/hooks]** A hook written from that reference would never block anything. The reference needs its own fix pass.
2. **I didn't use the reference's evidence-file pattern.** In that pattern the agent writes `last-test-evidence.json` itself, so the hook trusts something the agent produced. This hook runs `npm test` itself and checks the actual exit code. It also avoids the reference script's `jq` and `stat -f` calls, which don't work on Windows. **[generalizable]**
3. **A gate that never releases loops forever.** If the suite can't be fixed, an unconditional block keeps the agent going indefinitely. This hook allows 3 consecutive blocked stops, then lets the turn end, writes a halt note and shows you a HALT message. **[project-specific: the cap of 3 comes from your CLAUDE.md halt trigger 4]**

## Where each piece goes

| Piece | Layer | Why there |
|---|---|---|
| Blocking on red tests | Hook (Stop) | Shipping with a red suite is unacceptable, so it needs enforcement, not a preference **[practitioner: obra/superpowers iron law]** |
| Explaining the gate to the agent | CLAUDE.md (short section) | So the agent understands the block and doesn't fight it |
| Script | `.claude/hooks/verify-tests.mjs` | Node is always present in an npm project, and the script works the same in PowerShell and bash |
| Hook state and log | `.claude/state/` (gitignored) | Holds the block counter, the last-green fingerprint and the run log |

## Script: `.claude/hooks/verify-tests.mjs`

```javascript
#!/usr/bin/env node
// Stop hook - verification iron law.
// Blocks Claude from ending its turn while `npm test` is failing.
// After MAX_BLOCKS consecutive blocks in one stop chain it releases the turn,
// writes a halt note, and surfaces a HALT message so an unfixable suite
// escalates to the operator instead of looping.
//
// Optional env vars:
//   VERIFY_TESTS_MAX_BLOCKS    consecutive blocks before release  (default 3)
//   VERIFY_TESTS_TIMEOUT_MS    npm test timeout in ms             (default 540000)
//   VERIFY_TESTS_ALWAYS_RUN=1  disable the unchanged-tree skip
//
// Exit semantics: exit 0 + JSON on stdout is the only decision channel.
// An unexpected internal error exits 1 (non-blocking, stderr shown to user):
// the gate fails open loudly rather than trapping the session.

import { spawnSync, execFileSync } from 'node:child_process';
import { createHash } from 'node:crypto';
import fs from 'node:fs';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const MAX_BLOCKS = intEnv('VERIFY_TESTS_MAX_BLOCKS', 3);
const TEST_TIMEOUT_MS = intEnv('VERIFY_TESTS_TIMEOUT_MS', 540_000);
const ALWAYS_RUN = process.env.VERIFY_TESTS_ALWAYS_RUN === '1';
const TAIL_LINES = 60;

const PROJECT_DIR =
  process.env.CLAUDE_PROJECT_DIR ||
  path.resolve(path.dirname(fileURLToPath(import.meta.url)), '..', '..');
const STATE_DIR = path.join(PROJECT_DIR, '.claude', 'state');
const LOG_FILE = path.join(STATE_DIR, 'verify-tests.log');
const GREEN_FILE = path.join(STATE_DIR, 'verify-tests-last-green.json');
const HALT_DIR = path.join(PROJECT_DIR, 'output', 'halt_notes');

function intEnv(name, fallback) {
  const n = Number.parseInt(process.env[name] ?? '', 10);
  return Number.isFinite(n) && n > 0 ? n : fallback;
}

function log(message) {
  try {
    fs.mkdirSync(STATE_DIR, { recursive: true });
    fs.appendFileSync(LOG_FILE, `${new Date().toISOString()} ${message}\n`);
  } catch (err) {
    process.stderr.write(`verify-tests: log write failed: ${err.message}\n`);
  }
}

function readJson(file) {
  try {
    return JSON.parse(fs.readFileSync(file, 'utf8'));
  } catch (err) {
    if (err.code !== 'ENOENT') log(`WARN unreadable state file ${file}: ${err.message}`);
    return null;
  }
}

function writeJson(file, data) {
  fs.mkdirSync(path.dirname(file), { recursive: true });
  fs.writeFileSync(file, JSON.stringify(data, null, 2));
}

function removeFile(file) {
  try {
    fs.rmSync(file, { force: true });
  } catch (err) {
    log(`WARN could not remove ${file}: ${err.message}`);
  }
}

// fs.writeSync is synchronous on every platform; process.stdout to a pipe is not.
function allow(systemMessage) {
  if (systemMessage) fs.writeSync(1, JSON.stringify({ systemMessage }));
  process.exit(0);
}

function block(reason) {
  fs.writeSync(1, JSON.stringify({ decision: 'block', reason }));
  process.exit(0);
}

function readInput() {
  try {
    const raw = fs.readFileSync(0, 'utf8');
    return raw.trim() ? JSON.parse(raw) : {};
  } catch (err) {
    log(`WARN could not parse hook input: ${err.message}`);
    return {};
  }
}

// Hash of HEAD + working-tree diff + untracked file contents, excluding hook state.
// Lets Q&A-only turns skip the suite when nothing changed since the last green run.
function treeFingerprint() {
  const git = (args) =>
    execFileSync('git', args, {
      cwd: PROJECT_DIR,
      encoding: 'utf8',
      maxBuffer: 64 * 1024 * 1024,
      stdio: ['ignore', 'pipe', 'ignore'],
      windowsHide: true,
    });
  try {
    const hash = createHash('sha256');
    hash.update(git(['rev-parse', 'HEAD']));
    hash.update(git(['diff', 'HEAD', '--binary', '--', '.', ':(exclude).claude/state']));
    const untracked = git(['ls-files', '--others', '--exclude-standard', '-z'])
      .split('\0')
      .filter((rel) => rel && !rel.startsWith('.claude/state/'))
      .sort();
    for (const rel of untracked) {
      hash.update(rel);
      hash.update(fs.readFileSync(path.join(PROJECT_DIR, rel)));
    }
    return hash.digest('hex');
  } catch (err) {
    log(`INFO no git fingerprint (${String(err.message).split('\n')[0]}); running suite`);
    return null;
  }
}

function runTests() {
  if (!fs.existsSync(path.join(PROJECT_DIR, 'package.json'))) {
    return { passed: false, summary: 'package.json not found at project root', output: '' };
  }
  const started = Date.now();
  const res = spawnSync('npm test', {
    cwd: PROJECT_DIR,
    shell: true,
    encoding: 'utf8',
    env: { ...process.env, CI: 'true', FORCE_COLOR: '0', NO_COLOR: '1' },
    timeout: TEST_TIMEOUT_MS,
    maxBuffer: 64 * 1024 * 1024,
    windowsHide: true,
  });
  const seconds = ((Date.now() - started) / 1000).toFixed(1);
  const output = `${res.stdout ?? ''}\n${res.stderr ?? ''}`;
  if (res.error?.code === 'ETIMEDOUT') {
    return { passed: false, summary: `timed out after ${seconds}s`, output };
  }
  if (res.error) {
    return { passed: false, summary: `could not run npm test: ${res.error.message}`, output };
  }
  if (res.status !== 0) {
    return { passed: false, summary: `exit ${res.status ?? res.signal}, ${seconds}s`, output };
  }
  return { passed: true, summary: `passed in ${seconds}s`, output };
}

function tail(text, n) {
  return text
    .replace(/\x1b\[[0-9;]*[A-Za-z]/g, '')
    .trimEnd()
    .split(/\r?\n/)
    .slice(-n)
    .join('\n');
}

function writeHaltNote(sessionId, result, outputTail) {
  const stamp = new Date().toISOString();
  const dir = fs.existsSync(HALT_DIR) ? HALT_DIR : STATE_DIR;
  const file = path.join(dir, `halt_verify-tests_${stamp.replace(/[:.]/g, '-')}.md`);
  const body = [
    '# Halt note - verify-tests Stop hook',
    '',
    `- Time: ${stamp}`,
    `- Session: ${sessionId}`,
    `- Trigger: iteration cap (${MAX_BLOCKS} consecutive blocked stops with npm test failing)`,
    `- Last result: ${result.summary}`,
    '',
    `## Last ${TAIL_LINES} lines of npm test output`,
    '',
    '```',
    outputTail || '(no output captured)',
    '```',
    '',
  ].join('\n');
  try {
    fs.mkdirSync(dir, { recursive: true });
    fs.writeFileSync(file, body);
    return file;
  } catch (err) {
    log(`ERROR could not write halt note: ${err.message}`);
    return '(halt note write failed; see .claude/state/verify-tests.log)';
  }
}

function main() {
  const input = readInput();
  const sessionId = String(input.session_id || 'unknown').replace(/[^A-Za-z0-9_-]/g, '_');
  const counterFile = path.join(STATE_DIR, `verify-tests-blocks-${sessionId}.json`);

  // A stop not caused by our own block starts a fresh chain.
  const priorBlocks = input.stop_hook_active ? (readJson(counterFile)?.blocks ?? 0) : 0;

  const fingerprint = ALWAYS_RUN ? null : treeFingerprint();
  if (fingerprint && readJson(GREEN_FILE)?.fingerprint === fingerprint) {
    log('SKIP tree unchanged since last green run');
    removeFile(counterFile);
    allow();
  }

  const result = runTests();

  if (result.passed) {
    log(`PASS ${result.summary}`);
    removeFile(counterFile);
    if (fingerprint) {
      try {
        writeJson(GREEN_FILE, { fingerprint, at: new Date().toISOString() });
      } catch (err) {
        log(`WARN could not record green fingerprint: ${err.message}`);
      }
    }
    allow();
  }

  const outputTail = tail(result.output, TAIL_LINES);

  if (priorBlocks >= MAX_BLOCKS) {
    removeFile(counterFile);
    const note = writeHaltNote(sessionId, result, outputTail);
    log(`RELEASE cap ${MAX_BLOCKS} reached (${result.summary}); halt note ${note}`);
    allow(
      `HALT: npm test still failing after ${MAX_BLOCKS} fix cycles (${result.summary}). ` +
        `Turn released WITHOUT a green suite. Halt note: ${note}`,
    );
  }

  try {
    writeJson(counterFile, { blocks: priorBlocks + 1, at: new Date().toISOString() });
  } catch (err) {
    // Without a persisted counter the cap cannot fire; never loop unbounded.
    log(`ERROR could not persist block counter: ${err.message}`);
    if (input.stop_hook_active) {
      allow(`HALT: verify-tests could not persist its block counter and released the turn. npm test is failing (${result.summary}).`);
    }
  }

  log(`FAIL ${result.summary} (block ${priorBlocks + 1}/${MAX_BLOCKS})`);
  block(
    [
      `VERIFICATION IRON LAW: \`npm test\` is failing (${result.summary}). You may not end your turn while the suite is red.`,
      `Fix cycle ${priorBlocks + 1} of ${MAX_BLOCKS}. Diagnose the root cause and fix the code under test.`,
      'Do not delete, skip, or weaken tests, and do not edit the test script or this hook, to get green.',
      `If the root cause is ambiguous, say so plainly. After ${MAX_BLOCKS} cycles the gate releases and the session halts for the operator.`,
      '',
      `--- last ${TAIL_LINES} lines of npm test output ---`,
      outputTail || '(no output captured)',
    ].join('\n'),
  );
}

try {
  main();
} catch (err) {
  log(`ERROR unexpected: ${err.stack || err.message}`);
  process.stderr.write(`verify-tests hook error (gate not enforced this stop): ${err.message}\n`);
  process.exit(1);
}
```

## CLAUDE.md addition (insert as a new section)

```markdown
## Verification gate

A Stop hook (`.claude/hooks/verify-tests.mjs`) runs `npm test` whenever you try to end a turn.
If the suite is red, the stop is blocked and the test output tail is returned to you.

- Fix the code, not the tests. Deleting, skipping, or weakening tests to get green is out of scope.
- Do not edit `.claude/hooks/**`, `.claude/settings.json`, or the `test` script in `package.json`.
- After 3 blocked stops in a row the hook releases the turn and writes a halt note. Treat that as
  halt-and-escalate: summarize the failure and the hypotheses tried, then stop.
- Banned completion phrases: "should work", "probably fine", "looks good".
```

Add `.claude/state/` to `.gitignore`. Otherwise the hook's own log and state files change the tree fingerprint, and Q&A turns never skip the suite.

## Halt triggers and scope

- **Halt:** 3 consecutive blocked stops release the turn with a HALT message and a halt note. The note goes in `output\halt_notes\` if that folder exists, otherwise `.claude\state\`.
- **Fails open on internal errors:** if the script itself crashes, it exits 1. The stop goes through and you see the error. This is deliberate so a broken hook can't trap the session. The trade-off is that the gate isn't enforced on that stop.
- **Tampering the hook can't catch:** the agent could still edit tests, the hook or `settings.json`. CLAUDE.md covers that as policy. To enforce it, add `permissions.deny` rules for `Edit` and `Write` on `.claude/hooks/**` and `.claude/settings.json`. The exact path-anchoring syntax is **[speculation; confirm with `/permissions`]**.
- **Skipping unchanged trees:** if nothing has changed since the last green run (by git fingerprint), the suite is skipped. This is a cost optimization I added, not a pattern from a source. Set `VERIFY_TESTS_ALWAYS_RUN=1` to turn it off. Outside git, or before the first commit, the suite runs on every stop.
- **Windows timeout gap:** on Windows, the 540 s timeout kills `cmd.exe` but may leave the test runner's child processes running **[speculation]**.
