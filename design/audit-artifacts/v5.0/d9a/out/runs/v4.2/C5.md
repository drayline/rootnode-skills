# Fix: Refuter approval doesn't control what lands

## 1. Diagnosis

**The core problem:** an ACCEPT from the Refuter isn't tied to any specific version of the code. It's a verdict on whatever the Refuter read in a working tree that keeps changing, and nothing checks at merge time that the merged files match the reviewed files. A CLAUDE.md line telling the Builder to stop editing would only be a request, not a block. That is anti-pattern §4.4, "enforcement-as-preference". `[Skill ref: cc-anti-patterns §4.4]` It also breaks your global rule to check the real artifact, not a stand-in: the approval is a stand-in for "this code was reviewed".

Three causes could produce this. They can occur together, and I can't tell from here which one you have:

| # | Possible cause | What you'd see |
|---|---|---|
| H1 | The Builder edits the main checkout, not an isolated worktree, so the Refuter reviews files that are still changing | Main checkout shows uncommitted changes during review; the Refuter's file reads differ within one run |
| H2 | The Builder keeps running, or gets resumed, after it reports (no stop condition, or the orchestrator asks it to "polish" after ACCEPT) | The transcript shows Builder tool calls after the Refuter's verdict |
| H3 | The orchestrator merges the branch tip or working tree instead of the reviewed commit | The reviewed state was never recorded as a commit ID (SHA); the merge takes whatever is newest |

The fix below works no matter which cause is real. Step 1 of the regression sweep (§5) still identifies the real one, so the change log records it.

**The rule the fix enforces:** the code that lands must be byte-for-byte the code that was approved, checked by commit ID at merge time. `[generalizable — applies to any review loop where reviewer and builder share files that can change]`

## 2. Where each piece of the fix lives

| What needs to happen | Mechanism | File |
|---|---|---|
| The Refuter reviews a fixed commit, not a working tree | Builder instructions + CLAUDE.md | `.claude/agents/builder.md` |
| The verdict names the exact commit reviewed | Refuter's required output format | `.claude/agents/refuter.md` |
| The approval is recorded by a script only | Script + a block on direct writes | `scripts/{PROJECT_CODE}_land.py record` |
| Only the approved commit can be merged | Script + blocks on raw git merge commands | `scripts/{PROJECT_CODE}_land.py land` + `.claude/settings.json` |
| Edits made after approval are caught | The land script refuses if the worktree has uncommitted changes or its latest commit isn't the approved one | same script |
| The Builder stops after reporting | Builder instructions + a turn limit (`maxTurns`) | `.claude/agents/builder.md` |

**Not included, on purpose:** a hook that blocks Builder edits during review. Once approval is tied to a commit ID, an edit after approval can't land; it only forces a new review. Add the blocking hook only if the regression sweep shows repeated re-review loops.

**Note:** under your global CLAUDE.md, changes to CLAUDE.md and settings.json are out of scope for the agent. You need to apply §3.1–3.3 and §3.6 yourself, or authorize them explicitly for this session.

### 3.7 New file: `scripts/{PROJECT_CODE}_land.py` (complete)

```python
"""Bind Refuter approval to an immutable SHA; land only that SHA.

Usage:
  python scripts/{PROJECT_CODE}_land.py record <verdict_json_path>
  python scripts/{PROJECT_CODE}_land.py land <sha> <worktree_path>
Exit codes: 0 ok | 2 usage | 3 verdict invalid | 4 no/invalid approval
            5 worktree drift | 6 trunk not fast-forwardable | 7 git error
"""
import json, re, subprocess, sys, datetime
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent
APPROVALS = ROOT / ".claude" / "state" / "approvals"
LOG = ROOT / ".claude" / "state" / "land_log.jsonl"
TRUNK = "{TRUNK}"
SHA_RE = re.compile(r"^[0-9a-f]{40}$")

def log(event, **kw):
    LOG.parent.mkdir(parents=True, exist_ok=True)
    rec = {"ts": datetime.datetime.now(datetime.timezone.utc).isoformat(), "event": event, **kw}
    with LOG.open("a", encoding="utf-8") as f:
        f.write(json.dumps(rec) + "\n")
    print(json.dumps(rec), file=sys.stderr)

def git(*args, cwd=ROOT):
    try:
        r = subprocess.run(["git", *args], cwd=cwd, capture_output=True, text=True, timeout=120)
    except (OSError, subprocess.TimeoutExpired) as e:
        log("git_error", args=args, error=str(e)); sys.exit(7)
    if r.returncode != 0:
        log("git_error", args=args, stderr=r.stderr.strip()); sys.exit(7)
    return r.stdout.strip()

def fail(code, event, **kw):
    log(event, **kw); sys.exit(code)

def record(path):
    try:
        v = json.loads(Path(path).read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError) as e:
        fail(3, "verdict_unreadable", path=path, error=str(e))
    for k in ("verdict", "base_sha", "start_sha", "end_sha", "tests"):
        if k not in v: fail(3, "verdict_missing_field", field=k)
    if v["verdict"] != "ACCEPT": fail(3, "verdict_not_accept", verdict=v["verdict"])
    if not all(SHA_RE.match(v[k] or "") for k in ("base_sha", "start_sha", "end_sha")):
        fail(3, "verdict_bad_sha")
    if v["start_sha"] != v["end_sha"]:
        fail(3, "review_subject_drifted", start=v["start_sha"], end=v["end_sha"])
    if v["tests"].get("exit_code") != 0: fail(3, "verdict_tests_not_green")
    APPROVALS.mkdir(parents=True, exist_ok=True)
    out = APPROVALS / f"{v['end_sha']}.json"
    if out.exists(): fail(3, "approval_already_exists", sha=v["end_sha"])
    out.write_text(json.dumps(v, indent=2), encoding="utf-8")
    log("approval_recorded", sha=v["end_sha"], base=v["base_sha"])

def land(sha, worktree):
    if not SHA_RE.match(sha): fail(2, "bad_sha_arg", sha=sha)
    rec_path = APPROVALS / f"{sha}.json"
    if not rec_path.exists(): fail(4, "no_approval", sha=sha)
    try:
        rec = json.loads(rec_path.read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError) as e:
        fail(4, "approval_unreadable", error=str(e))
    if rec.get("end_sha") != sha or rec.get("verdict") != "ACCEPT":
        fail(4, "approval_mismatch", sha=sha)
    wt = Path(worktree)
    if not wt.is_dir(): fail(2, "worktree_missing", worktree=worktree)
    head = git("rev-parse", "HEAD", cwd=wt)
    if head != sha: fail(5, "worktree_head_moved_after_approval", approved=sha, head=head)
    if git("status", "--porcelain", cwd=wt): fail(5, "worktree_has_uncommitted_edits", sha=sha)
    if git("status", "--porcelain"): fail(5, "main_checkout_dirty")
    if git("rev-parse", "--abbrev-ref", "HEAD") != TRUNK: fail(5, "main_checkout_not_on_trunk")
    trunk_sha = git("rev-parse", TRUNK)
    if subprocess.run(["git", "merge-base", "--is-ancestor", trunk_sha, sha], cwd=ROOT).returncode != 0:
        fail(6, "trunk_moved_needs_rereview", trunk=trunk_sha, sha=sha)
    git("merge", "--ff-only", sha)
    landed = git("rev-parse", TRUNK)
    if landed != sha: fail(7, "post_land_mismatch", landed=landed, sha=sha)
    log("landed", sha=sha, base=rec["base_sha"])

if __name__ == "__main__":
    if len(sys.argv) == 3 and sys.argv[1] == "record": record(sys.argv[2])
    elif len(sys.argv) == 4 and sys.argv[1] == "land": land(sys.argv[2], sys.argv[3])
    else: print(__doc__, file=sys.stderr); sys.exit(2)
```

The merge is fast-forward only, so the main branch ends up at exactly the approved commit and its files are the approved files. No test run or revert is needed after the merge.
