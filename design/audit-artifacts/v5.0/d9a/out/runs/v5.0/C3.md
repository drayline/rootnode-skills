DESIGN mode: a bounded Stop gate on `npm test` that runs the tests itself. The deliverable is below.

## Two changes from what you asked for

1. **The hook runs `npm test` itself.** The skill's reference version only reads a result file that the agent writes, and an agent can fake that file. Running the tests in the hook checks the real result instead. `[generalizable]`: this works for any project that has a test command.
2. **The gate is capped, so it isn't strictly "never."** A Stop hook that blocks with no limit can trap a session. The skill requires two limits, and taken literally the first (`stop_hook_active`) makes the gate a one-time nudge. I kept the limits but changed how the first one works:
   - `stop_hook_active=false` starts a new "episode" for each new turn.
   - Within an episode, the gate blocks until it has seen the same failure twice, or until it has blocked 6 times in total. After that it lets the agent stop, logs it, and shows you a warning.
   - If `stop_hook_active` is missing from the hook input, the counters never reset, so the caps still apply.
   - This is a deliberate change from the skill's reference version `[Anthropic docs — hooks, per skill ref verified 2026-10-22; re-verify field name]`.

Other decisions:
- **Written in Node, not bash.** An npm project always has Node. That avoids depending on jq, `sha256sum` and `stat`, which behave differently or are missing on Windows.
- **Skips re-runs when nothing changed.** If the git tree is unchanged since the last run, the hook reuses that result. A turn with no edits costs nothing.
- **Sets `CI=true`** so Vitest and Create React App test runners don't sit in watch mode and hit the timeout `[tool docs; verify for your runner]`.
- **Fails open if the hook itself breaks.** If the script crashes, it lets the stop through and shows a warning that the tests were not checked. A guard that can't keep its counters can't enforce its limits, so it must not block.

## 2. `.claude/hooks/verify-tests.mjs`

```js
#!/usr/bin/env node
// verify-tests.mjs — Stop hook: the turn may not end while `npm test` fails.
// Fail direction: closed, bounded per stop episode. Internal error: open, loud.
// Off-switch: VERIFY_GATE_OFF=1 (logged). State: .claude/state/ (gitignored).
import { spawnSync } from "node:child_process";
import { createHash } from "node:crypto";
import { appendFileSync, existsSync, mkdirSync, readFileSync, statSync, writeFileSync } from "node:fs";
import { join } from "node:path";

const env = process.env;
const MAX_SAME = posInt(env.VERIFY_GATE_MAX_SAME, 2);              // identical failures before release
const MAX_TOTAL = posInt(env.VERIFY_GATE_MAX_TOTAL, 6);            // blocks per episode, progress or not
const TEST_TIMEOUT_S = posInt(env.VERIFY_GATE_TEST_TIMEOUT_S, 540); // keep below hook timeout (600)
const TAIL_LINES = 40;
const TAIL_CHARS = 4000;

const input = readInput();
const sessionId = input.session_id ?? "unknown";
const projectDir = env.CLAUDE_PROJECT_DIR || input.cwd || process.cwd();
const stateDir = join(projectDir, ".claude", "state");
const statePath = join(stateDir, "verify-gate.json");
const logPath = join(stateDir, "verify-gate.log");
const evidencePath = join(stateDir, "last-test-evidence.json");

try {
  main();
} catch (err) {
  // A guard that cannot keep its bookkeeping must not trap the session: release, loudly.
  log("INTERNAL_ERROR", err?.stack ?? String(err));
  release(`verify-gate internal error (${err?.message ?? err}); npm test was NOT verified.`);
}

function main() {
  mkdirSync(stateDir, { recursive: true });
  if (input._inputError) log("INPUT_UNREADABLE", input._inputError);
  if (env.VERIFY_GATE_OFF === "1") { log("OFF", "VERIFY_GATE_OFF=1"); process.exit(0); }
  if (!existsSync(join(projectDir, "package.json"))) {
    writeEvidence({ status: "NOT_RUN", reason: "no package.json at project root" });
    log("NOT_RUN", "no package.json");
    process.exit(0);
  }

  const state = loadState();
  const fresh = { session: sessionId, total: 0, same: 0, lastFp: null };
  // stop_hook_active === false marks a fresh stop attempt (new episode). If the field is
  // absent, never reset on it, so the caps still bound the loop.
  if (input.stop_hook_active === false || state.episode?.session !== sessionId) state.episode = { ...fresh };

  const key = treeKey();
  let result = key && state.lastRun?.key === key ? { ...state.lastRun, cached: true } : null;
  if (!result) result = runTests(key);
  const { cached, ...persist } = result;
  state.lastRun = persist;

  if (result.notRun) {
    writeEvidence({ status: "NOT_RUN", reason: result.notRun, cached: !!cached });
    log("NOT_RUN", result.notRun);
    saveState(state);
    release(`verify-gate: ${result.notRun}; nothing was verified.`);
  }

  if (result.pass) {
    state.episode = { ...fresh };
    writeEvidence({ status: "PASS", exit_code: 0, duration_s: result.duration_s, tree_key: key, cached: !!cached });
    log(cached ? "PASS_CACHED" : "PASS", `${result.duration_s}s tree=${key ?? "n/a"}`);
    saveState(state);
    process.exit(0);
  }

  const ep = state.episode;
  ep.same = result.fp === ep.lastFp ? ep.same + 1 : 1;
  ep.lastFp = result.fp;
  ep.total += 1;
  const base = {
    exit_code: result.exit_code, failure: result.failure, duration_s: result.duration_s,
    fingerprint: result.fp, tree_key: key, cached: !!cached, episode_blocks: ep.total,
  };

  if (ep.same > MAX_SAME || ep.total > MAX_TOTAL) {
    const why = ep.same > MAX_SAME
      ? `no progress: identical failure on ${ep.same} consecutive stops`
      : `ceiling: ${ep.total} stops in this episode`;
    writeEvidence({ status: "RELEASED_FAILING", release_reason: why, ...base });
    log("RELEASE", `${why} fp=${result.fp}`);
    saveState(state);
    release(`verify-gate released the stop with npm test STILL FAILING (${why}). Treat this work as unverified.`);
  }

  writeEvidence({ status: "FAIL", ...base });
  log("BLOCK", `${result.failure} fp=${result.fp} same=${ep.same} total=${ep.total} stop_hook_active=${input.stop_hook_active}`);
  saveState(state);
  process.stderr.write(
    `npm test is failing (${result.failure}; block ${ep.total}/${MAX_TOTAL}). ` +
    `Next step: fix the cause of the failures below and re-run \`npm test\` until it passes. ` +
    `Do not delete, skip, or weaken tests to clear this gate. If the failure is outside this task's ` +
    `scope, say so plainly and name the failing tests; the gate releases after ${MAX_SAME} identical failures.\n\n` +
    `--- last ${TAIL_LINES} lines of npm test output ---\n${result.tail}\n`
  );
  process.exit(2);
}

function runTests(key) {
  const started = Date.now();
  const run = spawnSync("npm test", {
    cwd: projectDir, shell: true, encoding: "utf8", windowsHide: true,
    env: { ...env, CI: "true", FORCE_COLOR: "0" }, // CI=true keeps watch-by-default runners in run mode
    timeout: TEST_TIMEOUT_S * 1000, maxBuffer: 64 * 1024 * 1024,
  });
  const output = `${run.stdout ?? ""}\n${run.stderr ?? ""}`;
  const base = { key, exit_code: run.status ?? null, duration_s: Math.round((Date.now() - started) / 100) / 10 };
  if (/missing script:\s*"?test"?|Error: no test specified/i.test(output)) {
    return { ...base, notRun: 'no usable "test" script in package.json' };
  }
  let failure = null;
  if (run.error?.code === "ETIMEDOUT") failure = `npm test exceeded ${TEST_TIMEOUT_S}s and was killed`;
  else if (run.error) failure = `npm test did not complete (${run.error.code ?? run.error.message})`;
  else if (run.status !== 0) failure = `npm test exited ${run.status ?? `on signal ${run.signal}`}`;
  if (!failure) return { ...base, pass: true };
  return { ...base, pass: false, failure, fp: fingerprint(output), tail: tail(output) };
}

function treeKey() {
  const head = git(["rev-parse", "HEAD"]);
  if (head === null) return null; // not a repo, or no commits yet: always run
  const ex = ":(exclude).claude/state";
  const diff = git(["diff", "HEAD", "--binary", "--", ".", ex]);
  const untracked = git(["ls-files", "--others", "--exclude-standard", "-z", "--", ".", ex]);
  if (diff === null || untracked === null) return null;
  const h = createHash("sha256").update(head).update(diff);
  for (const f of untracked.split("\0").filter(Boolean)) {
    try { const s = statSync(join(projectDir, f)); h.update(`${f}\0${s.size}\0${s.mtimeMs}\0`); }
    catch { h.update(`${f}\0missing\0`); }
  }
  return h.digest("hex").slice(0, 16);
}

function git(args) {
  const r = spawnSync("git", args, { cwd: projectDir, encoding: "utf8", windowsHide: true, maxBuffer: 256 * 1024 * 1024 });
  return r.status === 0 ? r.stdout : null;
}

function fingerprint(out) {
  // Digits normalized away so timings and durations do not read as "progress".
  const norm = stripAnsi(out).replace(/\d+(\.\d+)?/g, "#").replace(/[ \t]+/g, " ")
    .split(/\r?\n/).map((l) => l.trim()).filter(Boolean).slice(-200).join("\n");
  return createHash("sha256").update(norm).digest("hex").slice(0, 16);
}

function tail(out) {
  const t = stripAnsi(out).split(/\r?\n/).filter((l) => l.trim()).slice(-TAIL_LINES).join("\n");
  return t.length > TAIL_CHARS ? `...${t.slice(-TAIL_CHARS)}` : t;
}

function stripAnsi(s) { return s.replace(/\x1b\[[0-9;?]*[ -\/]*[@-~]/g, ""); }

function posInt(v, d) { const n = Number.parseInt(v ?? "", 10); return n > 0 ? n : d; }

function readInput() {
  try { const raw = readFileSync(0, "utf8"); return raw.trim() ? JSON.parse(raw) : {}; }
  catch (e) { return { _inputError: e.message }; }
}

function loadState() {
  try { return JSON.parse(readFileSync(statePath, "utf8")); }
  catch (e) { if (existsSync(statePath)) log("STATE_RESET", e.message); return {}; }
}

function saveState(s) { writeFileSync(statePath, JSON.stringify(s, null, 2)); }

function writeEvidence(obj) {
  writeFileSync(evidencePath, JSON.stringify(
    { timestamp: new Date().toISOString(), session_id: sessionId, command: "npm test", ...obj }, null, 2));
}

function log(event, detail) {
  try { appendFileSync(logPath, `${new Date().toISOString()}\t${sessionId}\t${event}\t${String(detail).replace(/\s+/g, " ")}\n`); }
  catch { /* logging must never decide the gate */ }
}

function release(message) {
  process.stdout.write(JSON.stringify({ systemMessage: message })); // shown to the user; verify field on running version
  process.exit(0);
}
```

## Verification

A Stop hook runs `npm test` before every end of turn and blocks while it fails.
- Fix the cause of failures. Never delete, `.skip`, or weaken a test to clear the gate (halt and escalate instead).
- Never edit `.claude/hooks/`, `.claude/settings*.json`, or set `VERIFY_GATE_OFF`.

## 4. When the agent must stop and escalate

- Getting the tests green would mean changing a test's assertions, deleting a test, or skipping one. Deleting tests is out of scope under your global rules.
- The gate let the agent stop with `RELEASED_FAILING`. This matches your 3-cycle rule: two blocks on the same failure, then release on the third.
- The failure comes from code outside the task, or there are several plausible root causes.
- The gate reports `NOT_RUN` or an internal error. The run is unverified and must not be reported as done.

## Risks to know about

- **I haven't run any of this.** You asked me not to write files, so it hasn't been executed. Run the smoke test above before relying on it.
- **The agent can rewrite the gate.** Nothing stops it editing the hook file or `settings.json`; only the CLAUDE.md rule asks it not to. Add a separate edit-blocking hook on those paths only if you actually see it happen.
- **Flaky tests stick.** Results are reused until the tree changes, so a flaky failure keeps blocking until there's an edit.
- **Some changes go unnoticed.** Changes inside `node_modules` don't count as changes, so the hook may reuse an old result.
- **Windows timeouts.** Timing out `npm test` through `cmd` may leave orphaned processes running.
- **Shared state.** Two sessions running at once use the same state file.
- **Every edited turn pays the full suite.** If the suite takes minutes, point the hook at a faster `test` script.
