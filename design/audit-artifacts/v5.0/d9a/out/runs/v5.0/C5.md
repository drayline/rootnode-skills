# EVOLVE: Freezing what the Refuter approved so that is exactly what lands

**Verdict:** Your setup has no **receipt freeze**. An ACCEPT is not tied to the specific change it reviewed, and the Builder can still write to its working copy after the review, so the ACCEPT ends up vouching for whatever is there when the change lands. The fix moves this guarantee out of prompt text and into a mechanism:

- **Pin the change at submission.** When the Builder hands in its work, record its exact commit and a fingerprint of the change.
- **Tie the verdict to that commit.** An ACCEPT only counts if the Refuter reviewed that same fingerprint.
- **Block Builder edits after submission** with a hook.
- **Land the reviewed commit by its ID, after a check.** The Builder's later state is never what gets merged.

`[generalizable]`: the receipt-freeze pattern comes from `cc-delegation-patterns.md` §4 `[practitioner: aidlc aidlc-review-freeze.ts]`. The paths, scripts and commands below are specific to this design.

**Limits on what I could see:** your actual CLAUDE.md, agent files and session transcripts weren't available to me. So the changes below are tied to section names, not line numbers, and I can't yet tell which of four possible causes (§1) is the real one. The fix works whichever it is. Section 1 lists the evidence that would tell them apart. Nothing has been created or edited.

## 3. CLAUDE.md change: replace the "Builder-to-Refuter loop" section

```markdown
## Builder-to-Refuter loop (receipt-frozen)

Invariant: what lands is byte-identical to the commit the Refuter reviewed.
`scripts/receipts.py` and the receipt-freeze hook enforce it; this section
explains it. Receipts live in `<git-common-dir>/claude-receipts/` (shared by all
worktrees, outside the tracked tree).

1. Builder returns. Line 1 must read `ROLE: builder | SPEC_SHA256: … | HEAD: <sha> | TREE_CLEAN: yes`.
   Anything else: re-dispatch once, then halt.
2. Submit: `python scripts/receipts.py submit <task> <worktree> <base_sha>`.
   This freezes the Builder worktree. Never message or resume the Builder while
   its task is frozen.
3. Spawn a fresh, non-fork Refuter with the `reviewed_sha` and `diff_sha256` printed by submit.
4. ACCEPT: `python scripts/receipts.py accept <task> <refuter_agent_id> <DIFF_SHA256 from Refuter line 1>`.
   REWORK: `python scripts/receipts.py void <task> "REWORK: <must-fixes>"`, then message the
   same Builder by ID and return to step 2 with a new Refuter. Cycle cap: 2.
5. Before landing: `python scripts/receipts.py verify <task>`.
   Exit 5 (drift): void, then re-enter at step 2 with the Builder's newer commit (counts as a cycle).
6. On exit 0, give the operator the printed merge command. It merges by SHA, so post-review
   edits cannot land even if a guard was bypassed.

A Builder return with no commit is not reviewable. "Small fixes after ACCEPT" are a REWORK cycle.
```

## 4. Changes to scope authorization

**Autonomous:** `receipts.py submit | accept | void | verify | digest`. Re-dispatching a Refuter after a fingerprint mismatch.

**Allowed, with notification:** voiding a receipt to reopen review, and the drift re-entry in step 5. The change_log records both.

**Out of scope (halt and escalate):**
- Merging the reviewed commit into main (the operator runs the printed command)
- Editing receipt files by hand
- Setting `RECEIPT_FREEZE_OFF=1`
- Modifying the hook, `settings.json`, or `receipts.py`

## 5. New halt-and-escalate triggers

1. `receipts.py verify` exits 5 a **second** time on the same task. This is a structural problem, not a one-off.
2. The freeze hook blocks the same task's Builder twice. The Builder is ignoring its contract.
3. Any `receipts.py` exit 3 (receipt missing or unreadable) or exit 4 (git failure).
4. `RECEIPT_FREEZE_OFF` is found set during an unattended run.
5. Builder-to-Refuter cycle count would exceed 2 (the existing cap; drift re-entries count toward it).

## 9. `.claude/hooks/receipt_freeze_guard.py`

```python
#!/usr/bin/env python3
"""PreToolUse guard: refuse writes inside a Builder worktree frozen by a review receipt.
Exit 2 blocks, exit 0 allows. Fails closed on unreadable input or receipts.
Off-switch RECEIPT_FREEZE_OFF=1 is logged; forbidden in unattended runs."""
import datetime, json, os, pathlib, re, subprocess, sys

WRITE_TOOLS = {"Edit", "Write", "MultiEdit", "NotebookEdit"}
MUTATORS = re.compile(
    r"(?<![\d&-])>{1,2}(?!&)|\btee\b|\bsed\s+-i|\bperl\s+-i|\b(mv|rm|cp|truncate)\b|"
    r"\bgit\s+(checkout|restore|apply|am|stash|reset|commit|cherry-pick|rebase|merge)\b|"
    r"Set-Content|Add-Content|Out-File|Remove-Item|Move-Item|Copy-Item")
LOG = None

def log(line):
    if LOG:
        with open(LOG, "a", encoding="utf-8") as f:
            f.write(f"{datetime.datetime.now(datetime.timezone.utc).isoformat()} {line}\n")

def block(msg):
    log(f"block {msg}")
    print(msg, file=sys.stderr)
    sys.exit(2)

def norm(p):
    return os.path.normcase(os.path.realpath(p))

def inside(path, root):
    path, root = norm(path), norm(root)
    return path == root or path.startswith(root.rstrip(os.sep) + os.sep)

def mentions(cmd, root):
    return norm(root).replace("\\", "/") in os.path.normcase(cmd).replace("\\", "/")

def main():
    global LOG
    try:
        ev = json.load(sys.stdin)
    except (ValueError, OSError) as e:
        block(f"receipt-freeze: hook input unreadable ({e}); rule holds. Next step: check hook stdin wiring.")
    cwd = ev.get("cwd") or os.getcwd()
    try:
        r = subprocess.run(["git", "rev-parse", "--path-format=absolute", "--git-common-dir"],
                           cwd=cwd, capture_output=True, text=True, timeout=5)
    except (OSError, subprocess.TimeoutExpired) as e:
        block(f"receipt-freeze: git unavailable ({e}); rule holds. Next step: put git on PATH for hooks.")
    if r.returncode != 0:
        sys.exit(0)  # not a git repo: no receipts can exist
    rdir = pathlib.Path(r.stdout.strip()) / "claude-receipts"
    if not rdir.is_dir():
        sys.exit(0)
    LOG = rdir / "guard.log"
    frozen = []
    for p in rdir.glob("*.json"):
        try:
            rec = json.loads(p.read_text(encoding="utf-8"))
        except (ValueError, OSError) as e:
            block(f"receipt-freeze: {p.name} unreadable ({e}); rule holds. Next step: halt and escalate.")
        if rec.get("status") in ("under_review", "accepted"):
            frozen.append(rec)
    if not frozen:
        sys.exit(0)
    if os.environ.get("RECEIPT_FREEZE_OFF") == "1":
        log(f"override tool={ev.get('tool_name')}")
        sys.exit(0)
    tool, ti = ev.get("tool_name", ""), ev.get("tool_input") or {}
    hit = None
    if tool in WRITE_TOOLS:
        target = ti.get("file_path") or ti.get("notebook_path")
        if not target:
            block("receipt-freeze: write tool with no target path; rule holds. Next step: retry with an explicit path.")
        hit = next((f for f in frozen if inside(os.path.join(cwd, target), f["worktree"])), None)
    elif tool == "Bash" and MUTATORS.search(ti.get("command", "")):
        cmd = ti["command"]
        hit = next((f for f in frozen if inside(cwd, f["worktree"]) or mentions(cmd, f["worktree"])), None)
    if hit:
        block(f"receipt-freeze: worktree for task {hit['task_id']} is frozen ({hit['status']}, reviewed "
              f"{hit['reviewed_sha'][:12]}). Post-review edits do not land. Next step: stop and return "
              f"to the orchestrator; it voids the receipt to open a REWORK cycle.")
    sys.exit(0)

if __name__ == "__main__":
    main()
```

## 10. `scripts/receipts.py`

```python
#!/usr/bin/env python3
"""Bind a Refuter verdict to the exact diff it reviewed.
  submit <task> <worktree> <base>        freeze worktree; pin HEAD as reviewed_sha
  accept <task> <refuter_id> <digest>    record ACCEPT; refuse if digest != submitted
  void   <task> <reason>                 unfreeze for REWORK (history kept, append-only)
  verify <task>                          exit 0 only if nothing changed after review
  digest <base> <head>                   print LF-normalised sha256 of the diff (read-only)
Exit: 0 ok, 2 refused, 3 receipt missing/unreadable, 4 git failure, 5 drift."""
import datetime, hashlib, json, os, pathlib, re, subprocess, sys

def die(msg, code):
    print(f"receipts: {msg}", file=sys.stderr)
    sys.exit(code)

def git(*args, cwd=None):
    try:
        r = subprocess.run(["git", *args], cwd=cwd, capture_output=True, timeout=60)
    except (OSError, subprocess.TimeoutExpired) as e:
        die(f"git {' '.join(args)} could not run ({e})", 4)
    if r.returncode != 0:
        die(f"git {' '.join(args)} failed: {r.stderr.decode(errors='replace').strip()}", 4)
    return r.stdout

def rdir():
    d = pathlib.Path(git("rev-parse", "--path-format=absolute", "--git-common-dir").decode().strip()) / "claude-receipts"
    d.mkdir(exist_ok=True)
    return d

def now():
    return datetime.datetime.now(datetime.timezone.utc).isoformat(timespec="seconds")

def digest(base, head):
    raw = git("diff", "--binary", "--no-color", "--no-ext-diff", f"{base}..{head}")
    return hashlib.sha256(raw.replace(b"\r\n", b"\n")).hexdigest()

def path_for(task):
    if not re.fullmatch(r"[A-Za-z0-9._-]+", task):
        die(f"invalid task id {task!r}", 2)
    return rdir() / f"{task}.json"

def load(task):
    p = path_for(task)
    if not p.exists():
        die(f"no receipt for task {task}", 3)
    try:
        return p, json.loads(p.read_text(encoding="utf-8"))
    except ValueError as e:
        die(f"receipt {p.name} unreadable ({e}); halt and escalate", 3)

def save(p, rec, event):
    rec.setdefault("history", []).append({"at": now(), **event})
    tmp = p.with_suffix(".tmp")
    tmp.write_text(json.dumps(rec, indent=2), encoding="utf-8")
    os.replace(tmp, p)

def submit(task, worktree, base):
    p = path_for(task)
    rec = json.loads(p.read_text(encoding="utf-8")) if p.exists() else {"task_id": task}
    if rec.get("status") in ("under_review", "accepted"):
        die(f"task {task} already frozen ({rec['status']}); void it first", 2)
    if git("status", "--porcelain", cwd=worktree).strip():
        die("worktree has uncommitted changes; the Builder must commit before review", 2)
    head = git("rev-parse", "HEAD", cwd=worktree).decode().strip()
    base = git("rev-parse", base).decode().strip()
    files = [f for f in git("diff", "--name-only", "-z", f"{base}..{head}").decode().split("\0") if f]
    rec.update(status="under_review", worktree=str(pathlib.Path(worktree).resolve()), base_sha=base,
               reviewed_sha=head, diff_sha256=digest(base, head), files=files, cycle=rec.get("cycle", 0) + 1)
    save(p, rec, {"event": "submit", "reviewed_sha": head, "cycle": rec["cycle"]})
    print(json.dumps({k: rec[k] for k in ("task_id", "reviewed_sha", "diff_sha256", "cycle")}))

def accept(task, refuter_id, reported):
    p, rec = load(task)
    if rec.get("status") != "under_review":
        die(f"task {task} is {rec.get('status')}, not under_review", 2)
    if reported != rec["diff_sha256"]:
        die(f"Refuter reviewed {reported[:12]}, submitted {rec['diff_sha256'][:12]}; verdict does not bind. "
            "Re-dispatch the Refuter.", 2)
    rec.update(status="accepted", refuter_agent_id=refuter_id)
    save(p, rec, {"event": "accept", "refuter": refuter_id})

def void(task, reason):
    p, rec = load(task)
    prev, rec["status"] = rec.get("status"), "voided"
    save(p, rec, {"event": "void", "from": prev, "reason": reason})

def verify(task):
    p, rec = load(task)
    problems = []
    if rec.get("status") != "accepted":
        problems.append(f"status is {rec.get('status')}, not accepted")
    wt = rec.get("worktree", "")
    if os.path.isdir(wt):
        head = git("rev-parse", "HEAD", cwd=wt).decode().strip()
        if head != rec["reviewed_sha"]:
            extra = git("log", "--oneline", f"{rec['reviewed_sha']}..{head}", cwd=wt).decode().strip()
            problems.append(f"Builder HEAD {head[:12]} != reviewed {rec['reviewed_sha'][:12]}; after review:\n{extra}")
        if git("status", "--porcelain", cwd=wt).strip():
            problems.append("uncommitted edits in the Builder worktree after review")
    else:
        print(f"note: worktree {wt} no longer exists; landing by SHA is unaffected")
    if problems:
        save(p, rec, {"event": "verify", "result": "drift", "problems": problems})
        die("DRIFT\n- " + "\n- ".join(problems), 5)
    save(p, rec, {"event": "verify", "result": "pass"})
    print(f"verified: lands exactly {rec['reviewed_sha']}\n"
          f"operator merge command: git merge --no-ff {rec['reviewed_sha']}")

CMDS = {"submit": (submit, 3), "accept": (accept, 3), "void": (void, 2), "verify": (verify, 1),
        "digest": (lambda b, h: print(digest(b, h)), 2)}

if __name__ == "__main__":
    if len(sys.argv) < 2 or sys.argv[1] not in CMDS or len(sys.argv) - 2 != CMDS[sys.argv[1]][1]:
        die(__doc__, 2)
    CMDS[sys.argv[1]][0](*sys.argv[2:])
```
