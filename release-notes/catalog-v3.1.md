## What's in v3.1

27 Skills across 9 functional categories. Two surfaces: chat-side Claude Projects and Claude Code execution. Unified by a single principle layer governing both.

The v3.1 ship is the Opus 4.8 apply-now alignment: voice and framing recalibrated across the catalog — reasoning-discipline scaffolding lightened to reasoned voice, advisory pipelines reframed to outcome anchors — with gates and methodology preserved in every Skill, plus `rootnode-session-handoff` v2.0. Test-gated tier changes and the README compatibility-matrix regeneration are deferred to v3.2.

**All Skills, one download:** grab `rootnode-catalog-v3.1.zip` from the Assets below. It bundles all 29 packaged Skill files (24 chat-side `-cp` flat zips for Claude Projects, 5 Claude Code `-cc` wrapper zips). Unzip it, then upload or install the Skills you want.

**Individual Skills:** use the links under Skills below — each Skill's own release carries its packaged zip.
